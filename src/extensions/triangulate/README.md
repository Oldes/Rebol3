# Rebol/Triangulat extension

Triangulat bindings for Rebol 3, built either as a standalone extension library
(`triangulate.rebx`) or embedded directly into the host.

## This is a vendored copy

The main repository for this extension lives at:

**https://github.com/Siskin-Framework/Rebol-Triangulate**

The sources here are a snapshot kept in tree so the extension can be built
together with Rebol itself. The upstream repository may be more current, and
it is the place for:

* the latest version, including fixes not yet copied here
* issues and pull requests
* documentation and usage examples
* prebuilt releases

Please report problems and send changes upstream rather than against this
copy, unless the problem is specific to building it inside this repository.
