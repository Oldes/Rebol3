Enter runs the code, Shift+Enter adds a new line, ↑/↓ recall history. Drop files on the console to upload them.

This is a limited Rebol/Base build: some functions are not available, native extensions cannot be imported, call and keyboard input (read-key) do not work, and files are kept in memory only (use Upload or drop files on the console to copy your own files to %/uploads/).
